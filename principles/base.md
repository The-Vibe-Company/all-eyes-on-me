# Base principles

The principles every AEOM install starts from. Plain text, no images.

Each principle has an id in backticks, then what it asks for. The judge answers pass or fail for each one, on each page, and says why in one sentence.

This is a draft. It gets settled in a dedicated session, then grows with each person's feedback in their personal layer.

- `pointer` — Everything clickable looks clickable: a pointer cursor, and a visible difference from plain text.
- `one-direction` — One art direction, held on every page. No page borrows another style.
- `consistent-chrome` — The header, the navigation and the buttons are the same on every page: same place, same look, same order.
- `not-generic` — Nothing generic: no purple-to-blue gradient, no shadowed cards everywhere, no decorative emoji, no layout that could be any SaaS template.
- `hierarchy` — A clear hierarchy, with one focal point per page. The eye knows where to start.
- `grid` — Elements line up on a grid. Edges, gutters and baselines agree.
- `density` — Density is controlled: nothing cramped, nothing lost in empty space.
- `states` — Empty, error and loading states exist and say what is happening and what to do next. A blank area is a failure.
